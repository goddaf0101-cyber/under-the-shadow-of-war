# ใต้เงาสงคราม (WW3 Thailand Survival) — ต้นแบบ

เกมเอาชีวิตรอดแบบเล่าเรื่องบนมือถือ ประเทศไทยในสงครามโลกครั้งที่ 3 เล่นผ่านเบราว์เซอร์ได้ทันที

- สถานะ: ต้นแบบ (prototype) — บท V5.0 และตัวเลขสมดุลยังเป็นร่างรอตรวจ
- เล่นต่อได้แม้ออฟไลน์หลังเปิดครั้งแรก · เพิ่มลงหน้าจอโทรศัพท์ได้
- อันดับออนไลน์: ตั้งค่าใน `index.html` ที่ `window.WW3_ONLINE` (Supabase) — ว่างไว้ = ปิด
- ไฟล์นี้สร้างจากซอร์สของโปรเจกต์ (build_web) อย่าแก้ `index.html` ด้วยมือ
